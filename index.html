Notice

Bien démarrer avec MAELSTRÖM

MAELSTRÖM est un téléchargeur universel : vous lui donnez un lien, il récupère la vidéo ou l'audio. Il fonctionne avec plus de 1 700 sites.

Installation

Télécharger et lancer

Sous Windows

  1. Cliquez sur Télécharger Maelstrom.bat. Si votre navigateur signale le fichier, choisissez Conserver.
  2. Double-cliquez sur le fichier. Une fenêtre bleue « Windows a protégé votre ordinateur » peut apparaître : pas d'inquiétude, cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Suivez les instructions affichées dans la fenêtre : c'est prêt.

Sous Linux

  1. Ouvrez un terminal dans le dossier du fichier (clic droit → « Ouvrir un terminal ici »).
  2. Rendez le script exécutable : 
    chmod +x maelstrom.sh
  3. Lancez-le : 
    ./maelstrom.sh
Le fichier n'est pas signé numériquement : un certificat de signature coûte cher et le projet est encore en développement. Si vous avez un doute, vous pouvez l'envoyer à votre IA préférée ou à VirusTotal pour qu'ils l'analysent avant de l'ouvrir.

Utilisation

Télécharger une vidéo

  1. Copiez le lien de la vidéo ou de la musique dans votre navigateur.
  2. Collez-le dans MAELSTRÖM et validez avec Entrée.
  3. Choisissez le format proposé : le fichier arrive dans votre dossier de téléchargement.

Vous ne savez pas si un site est pris en charge ? Consultez la liste des sites compatibles.

FAQ

Questions fréquentes

Est-ce que c'est gratuit ?
Oui, entièrement. MAELSTRÖM est un projet open source, sans compte ni abonnement.
Pourquoi Windows affiche un avertissement ?
Le fichier n'est pas signé avec un certificat payant (à partir d'environ 100 € par an). Windows SmartScreen se méfie donc par défaut. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
Et sur Mac ou Linux ?
Linux est disponible avec le fichier maelstrom.sh. La version macOS arrive bientôt.
Un site ne fonctionne pas, que faire ?
Vérifiez son état dans la liste des sites : un point rouge signifie que l'extracteur est temporairement hors service.

Pourquoi Windows va se méfier

MAELSTRÖM est un projet open source et gratuit. Pour que Windows reconnaisse un fichier comme « de confiance », il faut le signer avec un certificat de signature de code, vendu à partir d'environ 100 € par an. Ce fichier n'est donc pas signé, et c'est tout à fait normal pour un projet comme celui-ci.

1 · Dans le navigateur

Chrome ou Edge peuvent signaler le fichier comme peu téléchargé ou potentiellement dangereux. Cliquez sur Conserver.

2 · Au lancement

La fenêtre bleue « Windows a protégé votre ordinateur » peut s'afficher. Cliquez sur Informations complémentaires puis Exécuter quand même.

Bon à savoir : même avec un certificat, SmartScreen peut afficher un avertissement tant qu'un fichier est récent.
